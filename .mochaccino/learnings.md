# Mochaccino Learnings

## Rules
<!-- Read on every activation. Hard constraints. -->
- [user-mandated 2026-05-10] Every design view must open with an "Orient" strip directly under the header. Four labelled lines: PURPOSE (what question this view answers), AUDIENCE (who reads it and how each uses it), HOW TO READ (where the eye goes first, how the page is structured), TAKEAWAY (what action or decision this view informs). Reason: cold-reading a design after weeks away fails when there is no orientation frame — the data alone reads as a roll of text. Apply to every new design and re-render any existing design that lacks it.
